## 目标

把 harness 从 2.1.211 对齐到 **2.1.220**。这批 changelog 的重心不在新功能，而在三处**会让 harness 说错话**的语义变化：模型档位（Claude Opus 5 成为默认 Opus、fast mode 换宿主）、subagent 嵌套深度（默认值两周内翻了两次）、以及一组新设置键。凡是 harness 拿来给用户下判断的静态知识（价格、替代模型、键说明、深度上限），都必须跟着官方语义走，否则它比不显示更糟——**一个说得斩钉截铁但过时的价格数字，用户是会当真的**。

版本区间说明：**2.1.213 有 npm 发布（2026-07-17）但官方 changelog 里没有任何条目**，本批不作推断，按"无公开变更"处理。

## 变更清单

### 1. 模型档位（MODEL-01 / MODEL-09）

`shared/data/model-pricing.ts`：

- `PRICING_UPDATED` → `2026-07-25`。
- 新增 **fast 溢价档** `/opus.*-fast\b/` → $10/$50，排在通用 `/opus/` 之前。同时在注释里写清它的**局限**：2.1.219 起 fast 已经从模型串（`claude-opus-4-6-fast` 这种）改成请求参数 `speed:"fast"`，参数式 fast 在 transcript 里与标准档同名，**无法区分，会按 $5/$25 低估**。宁可把这个盲区写在代码里，也不假装算得准。
- 通用 `/opus/` 档注释补 Opus 5：$5/$25 与 4.8 同价，`claude-opus-5` 与带上下文后缀的 `claude-opus-5[1m]` 都命中这条。

`shared/data/model-deprecations.ts`：替代模型全量从 `claude-opus-4-8` 改指 `claude-opus-5`（Opus 4.1/4.0/Opus 3 系）；`claude-opus-4-7-fast` 的 `fastSunset` 由"计划移除"改为已确认（2.1.219 正式移出 fast mode），去掉此前那个推测性的日期。

### 2. subagent 嵌套深度语义（ORCH-14）

`electron/services/session/agent-topology.ts`：把裸的 `depth >= 5` 提成具名常量 `PARSE_MAX_DEPTH`，并在注释里记下 CLI 侧默认值的三段变化——2.1.172 起五层 → **2.1.217 默认禁止嵌套（深度 1）** → **2.1.219 默认恢复到 3**（`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` 关掉）。

**解析上限仍保持 5，不跟着 CLI 默认值降**：历史会话和调高了该环境变量的会话都要能完整画出来。这里的常量是防环/防病态文件的解析护栏，不是对 CLI 行为的复刻——两者混为一谈会让老会话的拓扑被无声截断。

同批还有 per-session spawn 上限 200（2.1.212）、并发上限 20（2.1.217），限流值本身暂不在 UI 呈现，只登记在对照表。

### 3. `DirectoryAdded` hook（HOOK-14）

`shared/types/hook.ts` 加 `DirectoryAdded`（2.1.219：`/add-dir` 或 SDK `register_repo_root` 会话中途注册新工作目录之后触发），`src/pages/hooks/hookTypes.ts` 归入 session 分组，中英 `events` 说明补齐。

### 4. 新设置键（MISC-17）

`shared/data/settings-key-catalog.ts` + 中英 `catalog.*`：

| 键 | 版本 | 说明要点 |
|---|---|---|
| `sandbox.filesystem.disabled` | 2.1.216 | 跳过文件系统隔离，只保留网络出口管控 |
| `sandbox.network.strictAllowlist` | 2.1.219 | 白名单外主机直接拒绝，不再弹确认 |
| `workflowSizeGuideline` | 2.1.219 | workflow 规模档位；**写了此键 `/config` 里对应行会隐藏**——这条要写进说明，否则用户会以为 UI 坏了 |
| `emojiCompletionEnabled` | 2.1.217 | `:shortcode:` emoji 补全开关，默认开 |

## 本批只登记不实现

- **PERM-13**（2.1.214 权限语义修正）：单段 `dir/**`（如 `Edit(src/**)`）从"树里任意深度同名目录"收窄为只匹配 `<cwd>/dir`，hook `if:` 条件同规则，而 `deny`/`ask` 规则保持任意深度匹配。**权限构造器目前不提示这个作用域差异**，是本批留下的最大缺口——同一个写法在 allow 与 deny 下含义不同，正是用户会踩的地方。下一批优先补。
- **ORCH-15**（`/fork` 改后台会话、`/subtask` 更名）、**ORCH-16**（`/code-review` 后台化、`/deep-research` 与 `/verify` 只认手动触发）：后台 Agent 页要标 fork 血缘需要新的落盘契约，等真实样本。
